# suites/default

| task | muscle |
| --- | --- |
| `add-feature` | implement a stub function to a spec pinned down by tests |
| `fix-bug` | find and fix a bug the failing test points straight at |
| `refactor` | rename one function, update its one call site |
| `multi-file-refactor` | rename + signature change propagated across three call sites in three files |
| `failing-test-diagnosis` | root-cause a bug whose failing-test symptom misleadingly implicates the wrong layer |
| `env-discovery` | find the project's own (non-obvious) verification command with no README and no hint in the prompt |

0x02 — how it works

A teammate, not a text box.

No dashboards to learn, no standups to sit through. Talk to it like a coworker; it does the rest.

01

Mention it

Drop a task in Discord, plain English. "fix the flaky auth flow and ship it." That's the whole interface.

02

It delegates

Fans out to agents in isolated worktrees, supervises by digest, and benches the ones going sideways.

03

It ships

A second model red-teams the diff. If it holds, Beckett merges, signed, and pings you.

0x03 — the hire

Everything a good hire has. None of the onboarding.

  • It runs its own team

    Work fans out to a fleet of worker agents in isolated git worktrees, supervised in parallel by digest. No log firehose, no micromanaging.

  • Adversarial review

    A second model tries to break every change before it merges. Trust issues, but make it a feature.

  • Owns its identity

    Own machine, own GitHub, signed and verified commits.

  • Persistent memory

    A linked graph. It remembers you across sessions, unlike your last intern.

  • Ships its own infra

    Provisions DNS, tunnels, deploys. Live URLs on demand, zero hand-holding.

  • It rewrites itself

    Persona, skills, operating doctrine: all editable by Beckett, applied live.
